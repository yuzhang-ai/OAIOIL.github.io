# OAIOIL Portfolio Website 2.0

Personal portfolio site deployed with GitHub Pages.

## Core files

- `index.html` - page content and section structure.
- `styles.css` - visual design, layout, responsive styles, and animation states.
- `script.js` - browser interactions, canvas effects, scrolling, carousel, and copy actions.

## Assets

- `assets/portrait.jpg` - hero portrait image.
- `assets/tool-*.png` and `assets/tool-*.webp` - tool and collaborator logos used by the Tools section.
- `assets/vendor/lenis.min.js` - smooth scrolling library loaded before `script.js`.

## Deployment

GitHub Pages publishes the `site-v2` branch root. The unchanged `main` branch retains version 1.0. Both website versions are available via the header version switch. See [VERSIONS.md](VERSIONS.md) for publishing and rollback details.
